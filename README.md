# BoatNav chart packs

Chart data for the BoatNav marine navigation app: one PMTiles pack and one routing
grid for each UK region, listed in `index.json`. The files are served by GitHub Pages. They are generated:
don't edit them by hand.

## Not for navigation

These charts are a model, not an official chart. Depths are about 115 m resolution and can miss rocks,
shoals and wrecks. Use official charts for navigation.
